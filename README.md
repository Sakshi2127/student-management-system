# Student Management System

## About the Project

The Student Management System is a web-based application developed using Django and Python. It helps manage student information and academic results through an admin panel.

## Features

- **Home Page:** Provides the main interface of the application.
- **Admin Login:** Allows the administrator to log in.
- **Admin Panel:** Provides access to student management features.
- **Add Students:** Add student information to the system.
- **Add Student Results:** Enter and manage students' academic results.
- **View Student Results:** View student results through the application.

## Technologies Used

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite Database

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/Sakshi2127/student-management-system.git
   ```

2. Open the project directory:

   ```bash
   cd student-management-system/project_2
   ```

3. Install Django:

   ```bash
   pip install django
   ```

4. Apply database migrations:

   ```bash
   python manage.py migrate
   ```

5. Start the development server:

   ```bash
   python manage.py runserver
   ```

6. Open the application in your browser:

   `http://127.0.0.1:8000/`
